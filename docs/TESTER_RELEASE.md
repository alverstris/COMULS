# COMULS Anki tester

Download comuls-tester.ankiaddon below. Install Anki Desktop 26.09.3, then use Tools → Add-ons → Install from file and restart. Open Tools → COMULS, choose B1, B2 or C1, check French audio and prepare your first exercise.

This package includes all thirteen flashcard formats and 90 original examples, concurrent task-level ranges, lower-level repair, familiarisation, native Anki scheduling, manual ratings, exposure protection, workload limits, level changes, searchable references, local reports and optional study-data export.

Native TTS requires a working French voice. Task levels are provisional. The full vocabulary inventory is not automatically turned into cards, and its existing expression ratings are unchanged.

The release workflow checks Python policy/bridge logic, real Anki collections and review-history preservation, Qt management controls, all 90 browser card interfaces, and the unchanged source vocabulary before packaging. These automated checks do not certify platform audio or mobile compatibility. Complete the student-platform checks in docs/TESTER_CHECKLIST.md before a supervised study. Learning efficacy has not been established.

See docs/STUDENT_GUIDE.md for installation, daily use, data handling and limitations. SHA256SUMS verifies the package; source_audit.json records the source inventory inspected by this build.
