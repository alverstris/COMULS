# Imperial French pilot: organiser guide

## Intended use

This is a downloadable desktop Anki add-on with separate B1 and B2 course routes. The original pilot content covers all thirteen short flashcard formats. The source vocabulary's expression placements are unchanged. This course pack is not a claim that the full source inventory is ready to teach.

The first pilot can establish installation success, usability, workload and technical reliability. Learning effectiveness needs independent delayed assessments and an appropriate comparison condition.

## Before inviting students

Use the release whose attached verification report identifies the tested commit. Install its B1 and B2 packages on the actual Windows/macOS/Linux configurations students will use. Run the audio check with headphones and speakers. Have a French teacher inspect the course items, task estimates and generated recordings before treating them as validated instruction.

Automated checks establish software behavior and audio integrity. They cannot establish that a voice pronounces every connected-speech contrast naturally or that a task has a validated CEFR placement.

Prepare separate B1 and B2 student instructions. Keep the course route fixed during the measurement period unless a change is recorded. Agree a daily budget and whether diagnostics are enabled. Avoid increasing the default workload simply to make all formats appear on the first day.

A student can use the demo without providing their name to COMULS. If linking exports to assessments, assign a study code outside the add-on and keep the code-to-person mapping separately. Follow the course's own consent and research-governance process where applicable.

## Suggested feasibility pilot

- Start with a supervised installation and control tutorial.
- Use a fixed short daily study budget over ten teaching days.
- Record installation/audio failures, days practised, active minutes, cards reviewed, skips/reports, workload blocks and daily effort ratings.
- Keep B1 and B2 results separate. Report missing timing or assistance coverage explicitly.
- Collect exports only through the method agreed with participants. COMULS has no automatic research-data upload.

Do not infer fluency improvement from ease ratings, number of cards, on-card correctness or the add-on's “stable” labels.

## Assessment design

Use independent items that test transfer to new contexts as well as retention of taught material. Assess listening segmentation, sentence comprehension, vocabulary retrieval, grammar interpretation and controlled written transformation separately. Exclude speech production: COMULS does not train or assess it.

Use a baseline, an immediate post-test and a delayed test. Keep assessment answers out of the learning pack. For an effectiveness claim, include a comparison condition with comparable time and content exposure; predefine the main outcome and analysis before reviewing results.

Exported native reviews are authoritative for scheduling and respect native undo. Assistance/exposure coverage is incomplete outside the managed desktop. Unknown coverage must not be relabelled as unaided success.

## Distribution and support

GitHub release assets provide the B1/B2 installers, checksums, content/audio manifests and build verification. Students install one package using Tools → Add-ons → Install from file and restart Anki.

Updates preserve stable exercise identities and native history. Material answer-contract changes require a new exercise identity. Keep a record of the release used by each participant; avoid changing instructional content mid-pilot without documenting it.

Do not uninstall the add-on or delete a student's collection to resolve an ordinary card issue. Pause a defective exercise, retain its history, and record the release/exercise ID for repair.
